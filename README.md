# Прокат туристического снаряжения «Привал» (СДР)

Лабораторная работа №1 «Основы HTML», вариант 19.
Автор: Саяхов Даниэль, группа ИВТ-ПО-302Б.

Страницы сайта — HTML-шаблоны без CSS и JavaScript. Данные (снаряжение, список аренды,
договоры) хранятся в базе SQLite, к которой подключается сервер на Python (Flask).

## Страницы

| Адрес | Назначение |
|---|---|
| `/index.html` | Главная: описание сервиса и навигация |
| `/catalog.html` | Каталог снаряжения, выбор нескольких позиций сразу |
| `/detail.html?id=1` | Подробная страница снаряжения |
| `/collection.html` | Список аренды: таблица с `thead`, `tbody`, `tfoot`, `colspan`, `rowspan` |
| `/checkout.html` | Форма оформления договора аренды |
| `/contract.html?id=1` | Оформленный договор |
| `/admin.html` | Управление базой данных: добавление, изменение, удаление записей |
| `/credits.html` | Источники изображений: авторы и лицензии фотографий |

## Запуск на macOS

```
pip3 install -r requirements.txt
python3 download_photos.py
python3 app.py
```

Открыть в браузере: http://127.0.0.1:5000
Если порт 5000 занят (AirPlay): `python3 -m flask --app app run --port 5001` и адрес http://127.0.0.1:5001

## Запуск на Windows

```
pip install -r requirements.txt
python download_photos.py
python app.py
```

## Фотографии

Фото палатки «Ветер-3», рюкзака «Штурм 50», спального мешка, горелки и бутыли
уже лежат в `static/images/`. Для остальных позиций `download_photos.py` один раз
скачивает фотографии с Wikimedia Commons (свободные лицензии) и записывает авторов
и лицензии в `static/images/credits.json`. Пока фото не скачаны, сайт показывает рисунки SVG.

## База данных

Файл `rental.db` создаётся автоматически при первом запуске из `schema.sql` и `seed.sql`.
Вернуть базу к начальным данным: `python3 app.py --reset`
(после сброса снова выполнить `python3 download_photos.py` не нужно — фото уже на месте).

## Структура проекта

```
app.py               сервер Flask: маршруты, работа с базой
download_photos.py   загрузка фотографий с Wikimedia Commons
schema.sql           структура базы данных (таблицы)
seed.sql             начальные данные
templates/           HTML-шаблоны страниц
static/images/       рисунки (SVG) и фотографии снаряжения
```
